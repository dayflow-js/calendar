# Druck-Plugin (Print Plugin)

`@dayflow-pro/plugin-print` fügt DayFlow einen integrierten Druckdialog und einen flexiblen Multi-Format-Export hinzu. Es bietet interaktive Seitenvorschauen, Unterstützung für 9 Papierformate, Trackpad-Pinch-Zoom, Live-Tabellendaten-Vorschau und programmatischen Headless-Export.

| Format  | Ausgabe                                                                                                |
| :------ | :----------------------------------------------------------------------------------------------------- |
| `print` | Nativer Browser-Druckdialog, exakt auf das gewählte Papierformat skaliert; Druck oder PDF-Export       |
| `png`   | Hochauflösendes Bild pro Seite; mehrseitige Exporte werden als ZIP-Archiv heruntergeladen              |
| `xlsx`  | Native Excel-Arbeitsmappe: Arbeitsblatt **Events** (Termine) und **Summary** (Statistik nach Kalender) |
| `ics`   | Standard-iCalendar-Datei für Google Kalender, Apple Kalender, Outlook und andere Kalender-Apps         |

Probieren Sie die [Live-Demo](https://pro.dayflow.studio/?utm_source=calendar.dayflow.studio&utm_medium=referral&utm_content=docs_print) aus.

Das Plugin stellt Hilfsmethoden direkt auf der Kalender-Instanz bereit:

```tsx
// Öffnet den Dialog mit Standardformat
await calendar.app.openPrintDialog();

// Öffnet den Dialog vorausgewählt mit Format oder Ansicht
await calendar.app.openPrintDialog({ format: 'xlsx', view: 'month' });

// Löst den nativen Druckdialog aus
await calendar.app.print();

// Programmatischer Headless-Export ohne UI
const result = await calendar.app.exportCalendar({
  format: 'png',
  view: 'week',
});
```

## Hauptfunktionen

- **4 Exportformate**: Print/PDF, PNG (einzeln oder als ZIP-Archiv), Excel (.xlsx) und iCalendar (.ics).
- **9 Papierformate**: `A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`.
- **Interaktiver Vorschaudialog**: Maßstabsgetreue Seitenvorschau, Trackpad-Pinch-Zoom, Drag-Pan und dynamisches Layout.
- **Live-Datenvorschau**: Anzeige einer interaktiven Tabellenansicht vor dem Download bei Auswahl von `xlsx` oder `ics`.
- **Headless-Export**: Direkter Aufruf über `calendar.app.exportCalendar()` oder `printPlugin.api.export()`.
- **Filterung**: Filterung nach Kalendern, ganztägigen Terminen und Terminen mit Uhrzeit.
- **Tastenkürzel**: Auslösen mit `Cmd + P` oder `Strg + P`.

## Programmatischer Export (Headless)

```ts
const result = await calendar.app.exportCalendar({
  format: 'xlsx',
  view: 'month',
  startDate: new Date(2026, 8, 1),
  endDate: new Date(2026, 11, 1),
  calendarIds: ['work', 'personal'],
  download: true, // auf false setzen, um result.blob ohne Dateidownload zu erhalten
  pixelRatio: 3, // für PNG-Auflösung (1 = 96 DPI)
  onProgress: ({ completed, total }) => {
    console.log(`Seite ${completed} von ${total} gerendert`);
  },
});

console.log(result.filename); // 'calendar-2026-09_2026-12.xlsx'
console.log(result.eventCount); // Anzahl exportierter Termine
console.log(result.pageCount); // Anzahl gerenderter Seiten (0 bei xlsx und ics)
console.log(result.blob); // Blob-Instanz, wenn download: false
```

### CalendarExportRequest Optionen

| Option        | Typ                                                        | Standard         | Beschreibung                                                                     |
| :------------ | :--------------------------------------------------------- | :--------------- | :------------------------------------------------------------------------------- |
| `format`      | `'print' \| 'png' \| 'xlsx' \| 'ics'`                      | Erforderlich     | Zielformat für den Export.                                                       |
| `view`        | `PrintView`                                                | Aktuelle Ansicht | Layout (`day`, `week`, `month`, `year-fixed-week`, `year-canvas`).               |
| `paper`       | `PaperSize`                                                | Aktuelle Auswahl | Papierformat (`A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`). |
| `orientation` | `'portrait' \| 'landscape'`                                | Ansichtsstandard | Seitenausrichtung.                                                               |
| `startDate`   | `Date`                                                     | Heutiges Datum   | Startdatum des Bereichs.                                                         |
| `endDate`     | `Date`                                                     | Automatisch      | Enddatum des Bereichs.                                                           |
| `calendarIds` | `string[]`                                                 | Alle Kalender    | Enthaltene Kalender-IDs.                                                         |
| `options`     | `Partial<CalendarPrintOptions>`                            | Plugin-Defaults  | Typografie-, Legenden- und Filteroptionen.                                       |
| `filename`    | `string`                                                   | Automatisch      | Benutzerdefinierter Dateiname ohne Endung.                                       |
| `download`    | `boolean`                                                  | `true`           | Wenn `false`, wird `result.blob` ohne automatischen Download zurückgegeben.      |
| `pixelRatio`  | `number`                                                   | `3`              | PNG-Auflösungsmultiplikator (1 = 96 DPI).                                        |
| `onProgress`  | `(progress: { completed: number; total: number }) => void` | —                | Fortschritts-Callback nach jeder gerenderten PNG-Seite.                          |
| `signal`      | `AbortSignal`                                              | —                | Signal zum Abbrechen mehrseitiger Exporte.                                       |

## Plugin-Konfiguration (PrintPluginConfig)

```ts
const printPlugin = createPrintPlugin({
  formats: ['print', 'png', 'xlsx', 'ics'],
  filename: ({ format, view, rangeStart, rangeEnd }) => `kalender-${view}`,
  pixelRatio: 3,
  defaultOptions: {
    miniCalendar: true,
    calendarKeys: true,
    textSize: 'medium',
  },
});
```

| Eigenschaft      | Typ                                                              | Standard                          | Beschreibung                                   |
| :--------------- | :--------------------------------------------------------------- | :-------------------------------- | :--------------------------------------------- |
| `enabled`        | `boolean`                                                        | `true`                            | Bei `false` wird das Plugin deaktiviert.       |
| `formats`        | `CalendarExportFormat[]`                                         | `['print', 'png', 'xlsx', 'ics']` | Formate und deren Reihenfolge im Dialog.       |
| `filename`       | `string \| ((context: CalendarExportFilenameContext) => string)` | —                                 | Dateiname oder Generator-Funktion.             |
| `pixelRatio`     | `number`                                                         | `3`                               | Standard-Auflösungsmultiplikator für PNG.      |
| `defaultOptions` | `Partial<CalendarPrintOptions>`                                  | —                                 | Voreingestellte Druckoptionen.                 |
| `license`        | `PackageLicenseConfig`                                           | —                                 | Lizenzkonfiguration bei individueller Nutzung. |

## CalendarPrintOptions

| Eigenschaft     | Typ                              | Standard | Beschreibung                         |
| :-------------- | :------------------------------- | :------- | :----------------------------------- |
| `allDayEvents`  | `boolean`                        | `true`   | Ganztägige Termine einschließen.     |
| `timedEvents`   | `boolean`                        | `true`   | Termine mit Uhrzeit einschließen.    |
| `miniCalendar`  | `boolean`                        | `true`   | Mini-Kalender im Kopfbereich zeigen. |
| `calendarKeys`  | `boolean`                        | `true`   | Kalenderlegende anzeigen.            |
| `blackAndWhite` | `boolean`                        | `false`  | Schwarz-Weiß-Druckmodus.             |
| `textSize`      | `'small' \| 'medium' \| 'large'` | `medium` | Typografie- und Layoutdichte.        |

## Plugin API
