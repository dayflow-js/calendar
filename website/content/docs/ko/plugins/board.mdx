# 보드 플러그인

보드 플러그인은 DayFlow에 할 일 보드 뷰를 추가합니다. 캘린더의 [할 일](/docs-ko/features/tasks)(`kind: 'task'`)을
상태, 우선순위 또는 담당자별 열로 보여 줍니다. 카드는 열 사이로 드래그할 수 있고, 모든 변경 사항은
캘린더의 일반 이벤트와 콜백으로 저장되므로 별도의 데이터 저장소가 필요하지 않습니다.

[인터랙티브 데모](/demo?view=board)에서 직접 사용해 볼 수 있습니다.

## 사용법

보드는 뷰입니다. 다른 캘린더 뷰와 함께 `views`에 등록하세요. `enableTasks: true`가 필요하며,
`taskMembers`로 할 일을 할당할 수 있는 멤버를 지정합니다.

## 할 일 데이터

열, 우선순위, 담당자는 모두 할 일 필드이므로 보드, 캘린더 뷰, 할 일 편집기가 같은 값을 읽고 씁니다.
`taskStatuses`와 `taskMembers` 옵션은 [상태와 담당자](/docs-ko/features/tasks#statuses-and-assignees)를 참고하세요.

| 필드               | 의미                                                         |
| ------------------ | ------------------------------------------------------------ |
| `task.status`      | `taskStatuses`의 열 ID(기본값 `todo`, `in-progress`, `done`) |
| `task.assigneeIds` | `taskMembers`의 멤버 ID                                      |
| `task.priority`    | `'none' \| 'low' \| 'medium' \| 'high'`                      |
| `task.completed`   | 완료 체크박스. `completed` 상태와 동기화됩니다               |
| `start`            | 마감일. 보드에서 만든 할 일은 오늘, 종일로 설정됩니다        |

- `completed: true`인 상태가 있으면 카드를 그 열로 옮길 때 할 일이 완료되고, 밖으로 옮기면 다시 열립니다.
  다른 곳에서 할 일을 완료하면 첫 번째 완료 상태로 이동합니다.
- 완료 상태가 없으면 체크박스와 열은 서로 독립적입니다.
- 담당자별로 그룹화하면 카드는 첫 번째 담당자의 열에 속합니다. 카드를 옮기면 그 담당자만 바뀌고
  나머지는 유지됩니다. **Unassigned**로 옮기면 모든 담당자가 해제됩니다.
- 보드는 캘린더의 표시 여부와 읽기 전용 설정을 따릅니다.

## 보드 사용하기

- **카드 이동**: 열 사이로 드래그하면 상태, 우선순위 또는 담당자가 바뀌고, 열 안에서 드래그하면 순서가 바뀝니다.
  포커스된 카드는 **Alt + 방향키** 또는 **Alt + Home/End**로도 이동할 수 있습니다.
- **카드 열기**: 카드를 클릭하면 할 일 편집기에서 제목, 열, 우선순위, 담당자, 마감일, 메모를 수정할 수 있습니다.
- **할 일 추가**: 열 머리글의 **＋** 또는 열 하단의 **New task**는 그 열의 상태, 우선순위 또는 담당자를 가진 할 일을 추가합니다.
- **열 편집**: 상태 열의 제목을 클릭하면 이름을 바꿀 수 있고, **⋯** 메뉴에서 이름 변경, 색상 변경, 삭제를 할 수 있습니다.
  열을 삭제할 때는 할 일을 다른 열로 병합할지 함께 삭제할지 묻습니다. **Add column**으로 상태를 추가합니다.
- **열 순서 변경**: 열 머리글을 드래그하거나, 포커스된 머리글에서 **Alt + 왼쪽/오른쪽**을 누릅니다.
- **그룹화와 필터**: **Group by**로 상태, 우선순위, 담당자를 전환합니다. 멤버 아바타를 클릭하면 그 멤버의 할 일만 표시합니다.

상태 열을 수정하면 `app.setTaskStatuses`와 `onTaskStatusesChange` 콜백이 호출되므로 거기서 저장하세요.

## 옵션

| 옵션              | 타입                                            | 기본값     | 설명                                       |
| ----------------- | ----------------------------------------------- | ---------- | ------------------------------------------ |
| `label`, `title`  | `string`                                        | `'Board'`  | 뷰 전환기 이름, 보드의 접근성 이름         |
| `groupBy`         | `'status' \| 'priority' \| 'assignee'`          | `'status'` | 초기 그룹화 방식                           |
| `allowStatusEdit` | `boolean`                                       | `true`     | 상태 열 추가, 이름 변경, 색상 변경, 삭제   |
| `allowCreate`     | `boolean`                                       | `true`     | **New task** 표시. 쓰기 권한도 필요합니다  |
| `initialState`    | `BoardViewState`                                | -          | 저장된 그룹화, 열과 카드 순서, 담당자 필터 |
| `messages`        | `Partial<BoardMessages>`                        | -          | 화면 문구 재정의(영어와 중국어 내장)       |
| `columnWidth`     | `number`                                        | -          | 열 너비(px), 최소 220                      |
| `showDescription` | `boolean`                                       | `true`     | 카드에 할 일 메모 표시                     |
| `cardFields`      | `{ priority?, description?, due?, assignees? }` | -          | `false`로 설정한 항목을 카드에서 숨깁니다  |
| `cardClassName`   | `string \| (args) => string`                    | -          | 카드의 클래스 이름                         |
| `cardStyle`       | `object \| (args) => object`                    | -          | 카드의 인라인 스타일                       |
| `renderCard`      | `({ event, app, open }) => ComponentChildren`   | -          | 카드 제목 아래에 추가할 Preact 콘텐츠      |

`cardClassName`과 `cardStyle`은 `{ event, app, groupId, groupBy }`를 받습니다.

### 콜백

| 콜백                | 호출 시점                                                                     |
| ------------------- | ----------------------------------------------------------------------------- |
| `onTaskMove`        | 드래그나 키보드로 이동하기 전: `{ event, from, to, groupBy }`. `false`면 취소 |
| `onTaskCreate`      | **New task**가 할 일을 추가하기 전. 수정한 초안이나 `false`를 반환합니다      |
| `onColumnDelete`    | 열 삭제를 확인한 후. `false`면 취소                                           |
| `onCardClick`       | 카드를 클릭하거나 Enter로 열 때. `false`면 편집기를 열지 않습니다             |
| `onViewStateChange` | 그룹화, 열·카드 순서, 필터가 바뀔 때. 여기서 상태를 저장합니다                |
| `onError`           | 할 일 저장이나 상태 알림이 실패했을 때                                        |

할 일 데이터 변경은 여전히 캘린더 콜백(`onEventCreate`, `onEventUpdate`, `onEventDelete`, `onTaskStatusesChange`)으로도 전달됩니다.

## 보드 레이아웃 저장하기

그룹화, 열 순서, 카드 순서, 담당자 필터는 화면 표시용 상태이며 할 일 자체를 바꾸지 않습니다.
`onViewStateChange`가 변경을 알려 주고, `initialState`로 복원합니다.

```ts
const board = createBoardView({
  initialState:
    JSON.parse(localStorage.getItem('board') ?? 'null') ?? undefined,
  onViewStateChange: state =>
    localStorage.setItem('board', JSON.stringify(state)),
});
```

`board.getState(app)`와 `board.setState(app, state)`로 코드에서 상태를 읽고 교체할 수 있습니다.
뷰 팩토리는 안정적으로 유지하세요. 같은 팩토리를 공유해도 캘린더마다 상태는 따로 유지됩니다.

## 카드 스타일

카드는 다음 CSS 사용자 지정 속성을 읽으며, `.df-board`, 열 또는 개별 카드에 설정할 수 있습니다.

| 속성                                                         | 기본값                        |
| ------------------------------------------------------------ | ----------------------------- |
| `--df-board-card-bg`                                         | `var(--df-color-card)`        |
| `--df-board-card-fg`                                         | 상속                          |
| `--df-board-card-radius`                                     | `0.5rem`                      |
| `--df-board-card-padding`                                    | `0.625rem 0.75rem 0.6875rem`  |
| `--df-board-card-gap`                                        | `0.375rem`                    |
| `--df-board-card-shadow`, `--df-board-card-shadow-hover`     | 얇은 테두리와 부드러운 그림자 |
| `--df-board-card-title-size`, `--df-board-card-title-weight` | `0.875rem`, `500`             |

각 카드에는 `data-priority`, `data-group`, `data-calendar`, `data-completed`,
`data-due`(`overdue`, `today`, `upcoming`) 속성도 있습니다.

```css
.df-board-card[data-due='overdue'] {
  box-shadow: inset 3px 0 #ef4444;
}
```

## 제한 사항

- 보드는 캘린더에 불러온 모든 날짜의 할 일을 보여 줍니다. 보이는 범위별로 이벤트를 불러온다면 보드용 할 일도 불러와야 합니다.
- 모든 할 일에는 마감일이 있습니다. 마감일 없는 할 일, 라벨, 하위 할 일은 아직 지원하지 않습니다.
- `renderCard`는 Preact 콘텐츠를 반환합니다. 프레임워크 네이티브 카드 슬롯은 아직 지원하지 않습니다.
