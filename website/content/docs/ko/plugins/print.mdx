# 인쇄 플러그인 (Print Plugin)

`@dayflow-pro/plugin-print`는 DayFlow에 기본 인쇄 대화상자와 다중 포맷 내보내기 워크플로를 추가합니다. 대화형 페이지 미리보기, 용지 크기 및 방향 제어, 트랙패드 핀치 줌, 스프레드시트 실시간 데이터 미리보기 및 헤드리스 내보내기 API를 지원합니다.

| 포맷    | 설명                                                                                      |
| :------ | :---------------------------------------------------------------------------------------- |
| `print` | 선택한 용지 크기에 맞춘 브라우저 인쇄 대화상자; 용지 인쇄 또는 PDF 저장 지원              |
| `png`   | 인쇄된 페이지당 고해상도 이미지; 여러 페이지는 ZIP 압축 파일로 다운로드                   |
| `xlsx`  | 네이티브 Excel 통합 문서: **Events** 시트(이벤트 목록) 및 **Summary** 시트(캘린더별 통계) |
| `ics`   | Google 캘린더, Apple 캘린더, Outlook 등을 위한 표준 iCalendar 파일                        |

[라이브 데모](https://pro.dayflow.studio/?utm_source=calendar.dayflow.studio&utm_medium=referral&utm_content=docs_print) 체험하기.

플러그인은 캘린더 인스턴스에 도우미 메서드를 직접 등록합니다:

```tsx
// 기본 인쇄 대화상자 열기
await calendar.app.openPrintDialog();

// 특정 포맷이나 뷰로 열기
await calendar.app.openPrintDialog({ format: 'xlsx', view: 'month' });

// 브라우저 기본 인쇄 트리거
await calendar.app.print();

// UI 없이 코드로 내보내기
const result = await calendar.app.exportCalendar({
  format: 'png',
  view: 'week',
});
```

## 주요 기능

- **4가지 내보내기 형식**: Print/PDF, PNG(단일 또는 다중 페이지 ZIP), Excel(.xlsx) 및 iCalendar(.ics).
- **9가지 용지 규격**: `A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`.
- **대화형 미리보기 대화상자**: 용지 크기 맞춤 미리보기, 트랙패드 핀치 줌, 드래그 이동.
- **실시간 데이터 미리보기**: `xlsx` 또는 `ics` 포맷 선택 시 대화상자 내에서 테이블 형식의 데이터 미리보기 제공.
- **헤드리스 프로그래밍 내보내기**: `calendar.app.exportCalendar()` 또는 `printPlugin.api.export()`를 호출하여 파일 또는 Blob 직접 획득.
- **캘린더 필터링**: 개별 캘린더, 종일 이벤트, 시간 지정 이벤트 필터링.
- **단축키 지원**: `Cmd + P` 또는 `Ctrl + P`로 인쇄 대화상자 실행.

## 코드에서 내보내기 (Headless Export)

```ts
const result = await calendar.app.exportCalendar({
  format: 'xlsx',
  view: 'month',
  startDate: new Date(2026, 8, 1),
  endDate: new Date(2026, 11, 1),
  calendarIds: ['work', 'personal'],
  download: true, // false로 설정하면 브라우저 다운로드 없이 result.blob을 반환합니다
  pixelRatio: 3, // PNG 해상도 배율 (1 = 96 DPI)
  onProgress: ({ completed, total }) => {
    console.log(`페이지 렌더링 완료: ${completed} / ${total}`);
  },
});

console.log(result.filename); // 'calendar-2026-09_2026-12.xlsx'
console.log(result.eventCount); // 내보낸 이벤트 개수
console.log(result.pageCount); // 렌더링된 페이지 수 (xlsx, ics는 0)
console.log(result.blob); // download: false 시 반환되는 Blob 객체
```

### CalendarExportRequest 옵션

| 옵션          | 타입                                                       | 기본값              | 설명                                                                          |
| :------------ | :--------------------------------------------------------- | :------------------ | :---------------------------------------------------------------------------- |
| `format`      | `'print' \| 'png' \| 'xlsx' \| 'ics'`                      | 필수                | 대상 내보내기 포맷.                                                           |
| `view`        | `PrintView`                                                | 현재 뷰             | 렌더링 레이아웃 (`day`, `week`, `month`, `year-fixed-week`, `year-canvas`).   |
| `paper`       | `PaperSize`                                                | 현재 선택           | 용지 규격 (`A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`). |
| `orientation` | `'portrait' \| 'landscape'`                                | 뷰 기본값           | 페이지 방향.                                                                  |
| `startDate`   | `Date`                                                     | 현재 날짜           | 내보내기 범위 시작일.                                                         |
| `endDate`     | `Date`                                                     | 자동 계산           | 내보내기 범위 종료일.                                                         |
| `calendarIds` | `string[]`                                                 | 모든 캘린더         | 포함할 캘린더 ID 배열.                                                        |
| `options`     | `Partial<CalendarPrintOptions>`                            | 플러그인 기본값     | 타이포그래피, 범례 및 이벤트 필터 옵션.                                       |
| `filename`    | `string`                                                   | 범위 기준 자동 생성 | 확장자를 제외한 파일 이름.                                                    |
| `download`    | `boolean`                                                  | `true`              | `false`일 경우 파일 저장을 건너뛰고 `result.blob`을 반환합니다.               |
| `pixelRatio`  | `number`                                                   | `3`                 | PNG 해상도 배율 (1 = 96 DPI).                                                 |
| `onProgress`  | `(progress: { completed: number; total: number }) => void` | —                   | PNG 페이지 래스터화 완료 시 콜백.                                             |
| `signal`      | `AbortSignal`                                              | —                   | 다중 페이지 내보내기 중단용 AbortSignal.                                      |

## 플러그인 설정 (PrintPluginConfig)

```ts
const printPlugin = createPrintPlugin({
  formats: ['print', 'png', 'xlsx', 'ics'],
  filename: ({ format, view, rangeStart, rangeEnd }) => `schedule-${view}`,
  pixelRatio: 3,
  defaultOptions: {
    miniCalendar: true,
    calendarKeys: true,
    textSize: 'medium',
  },
});
```

| 속성             | 타입                                                             | 기본값                            | 설명                                          |
| :--------------- | :--------------------------------------------------------------- | :-------------------------------- | :-------------------------------------------- |
| `enabled`        | `boolean`                                                        | `true`                            | `false`로 설정하면 플러그인이 비활성화됩니다. |
| `formats`        | `CalendarExportFormat[]`                                         | `['print', 'png', 'xlsx', 'ics']` | 대화상자에 표시할 포맷 목록 및 순서.          |
| `filename`       | `string \| ((context: CalendarExportFilenameContext) => string)` | —                                 | 파일 이름 또는 파일명 생성 함수.              |
| `pixelRatio`     | `number`                                                         | `3`                               | PNG 기본 해상도 배율.                         |
| `defaultOptions` | `Partial<CalendarPrintOptions>`                                  | —                                 | 사전 설정된 인쇄 및 표시 옵션.                |
| `license`        | `PackageLicenseConfig`                                           | —                                 | 개별 라이선스 설정.                           |

## CalendarPrintOptions

| 속성            | 타입                             | 기본값   | 설명                               |
| :-------------- | :------------------------------- | :------- | :--------------------------------- |
| `allDayEvents`  | `boolean`                        | `true`   | 종일 이벤트 포함 여부.             |
| `timedEvents`   | `boolean`                        | `true`   | 시간 지정 이벤트 포함 여부.        |
| `miniCalendar`  | `boolean`                        | `true`   | 인쇄 헤더에 미니 캘린더 표시.      |
| `calendarKeys`  | `boolean`                        | `true`   | 캘린더 범례 표시.                  |
| `blackAndWhite` | `boolean`                        | `false`  | 흑백 인쇄 모드.                    |
| `textSize`      | `'small' \| 'medium' \| 'large'` | `medium` | 미리보기 및 인쇄 텍스트 크기 밀도. |
