# Plugin de Impresión (Print Plugin)

`@dayflow-pro/plugin-print` añade un diálogo de impresión integrado y un flujo de exportación multiformato para DayFlow. Proporciona vistas previas interactivas, controles de tamaño y orientación del papel, zoom gestual con panel táctil, vista previa de datos tabulares en tiempo real y exportación programática sin interfaz.

| Formato | Salida                                                                                        |
| :------ | :-------------------------------------------------------------------------------------------- |
| `print` | Diálogo de impresión del navegador adaptado al papel seleccionado; imprime o guarda como PDF  |
| `png`   | Imagen de alta resolución por página impresa; varias páginas se descargan como archivo ZIP    |
| `xlsx`  | Libro de Excel nativo: hoja **Events** (eventos) y hoja **Summary** (resumen por calendario)  |
| `ics`   | Archivo iCalendar estándar para Google Calendar, Apple Calendar, Outlook y otras aplicaciones |

Pruebe la [demostración en vivo](https://pro.dayflow.studio/?utm_source=calendar.dayflow.studio&utm_medium=referral&utm_content=docs_print).

El plugin registra métodos directamente en la instancia del calendario:

```tsx
// Abre el diálogo con el formato predeterminado
await calendar.app.openPrintDialog();

// Abre el diálogo preseleccionando formato o vista
await calendar.app.openPrintDialog({ format: 'xlsx', view: 'month' });

// Desencadena el diálogo de impresión nativo
await calendar.app.print();

// Exportación programática sin abrir el diálogo
const result = await calendar.app.exportCalendar({
  format: 'png',
  view: 'week',
});
```

## Características principales

- **4 formatos de exportación**: Impresión/PDF, PNG (imagen única o archivo ZIP), Excel (.xlsx) e iCalendar (.ics).
- **9 tamaños de papel**: `A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`.
- **Diálogo interactivo de vista previa**: Escala precisa, zoom gestual con panel táctil, desplazamiento y ajuste dinámico.
- **Vista previa de datos en vivo**: Al seleccionar `xlsx` o `ics`, muestra una vista previa interactiva en tabla de los datos antes de la descarga.
- **Exportación headless**: Invoque directamente `calendar.app.exportCalendar()` o `printPlugin.api.export()` para obtener archivos o Blobs por código.
- **Filtrado por calendario y tipo**: Filtre calendarios individuales, eventos de día completo y eventos con hora.
- **Atajo global**: Presione `Cmd + P` o `Ctrl + P` para abrir el diálogo.

## Exportación por código (Headless)

```ts
const result = await calendar.app.exportCalendar({
  format: 'xlsx',
  view: 'month',
  startDate: new Date(2026, 8, 1),
  endDate: new Date(2026, 11, 1),
  calendarIds: ['work', 'personal'],
  download: true, // establezca en false para recibir result.blob sin descargar
  pixelRatio: 3, // multiplicador de resolución PNG (1 = 96 DPI)
  onProgress: ({ completed, total }) => {
    console.log(`Renderizada página ${completed} de ${total}`);
  },
});

console.log(result.filename); // 'calendar-2026-09_2026-12.xlsx'
console.log(result.eventCount); // cantidad de eventos exportados
console.log(result.pageCount); // páginas renderizadas (0 para xlsx e ics)
console.log(result.blob); // instancia Blob cuando download: false
```

### Opciones de CalendarExportRequest

| Opción        | Tipo                                                       | Predeterminado    | Descripción                                                                         |
| :------------ | :--------------------------------------------------------- | :---------------- | :---------------------------------------------------------------------------------- |
| `format`      | `'print' \| 'png' \| 'xlsx' \| 'ics'`                      | Requerido         | Formato de salida.                                                                  |
| `view`        | `PrintView`                                                | Vista actual      | Diseño (`day`, `week`, `month`, `year-fixed-week`, `year-canvas`).                  |
| `paper`       | `PaperSize`                                                | Selección actual  | Tamaño de papel (`A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`). |
| `orientation` | `'portrait' \| 'landscape'`                                | Predeterminado    | Orientación de la página.                                                           |
| `startDate`   | `Date`                                                     | Fecha actual      | Fecha de inicio del rango.                                                          |
| `endDate`     | `Date`                                                     | Calculado         | Fecha de finalización del rango.                                                    |
| `calendarIds` | `string[]`                                                 | Todos             | IDs de calendarios incluidos.                                                       |
| `options`     | `Partial<CalendarPrintOptions>`                            | Valores iniciales | Opciones de tipografía, leyenda y filtros.                                          |
| `filename`    | `string`                                                   | Auto-generado     | Nombre de archivo sin extensión.                                                    |
| `download`    | `boolean`                                                  | `true`            | Si es `false`, devuelve `result.blob` sin descarga en navegador.                    |
| `pixelRatio`  | `number`                                                   | `3`               | Multiplicador de resolución PNG (1 = 96 DPI).                                       |
| `onProgress`  | `(progress: { completed: number; total: number }) => void` | —                 | Callback de progreso por página PNG.                                                |
| `signal`      | `AbortSignal`                                              | —                 | Señal para cancelar exportaciones de múltiples páginas.                             |

## Configuración del plugin (PrintPluginConfig)

```ts
const printPlugin = createPrintPlugin({
  formats: ['print', 'png', 'xlsx', 'ics'],
  filename: ({ format, view, rangeStart, rangeEnd }) => `calendario-${view}`,
  pixelRatio: 3,
  defaultOptions: {
    miniCalendar: true,
    calendarKeys: true,
    textSize: 'medium',
  },
});
```

| Propiedad        | Tipo                                                             | Predeterminado                    | Descripción                                          |
| :--------------- | :--------------------------------------------------------------- | :-------------------------------- | :--------------------------------------------------- |
| `enabled`        | `boolean`                                                        | `true`                            | Deshabilita el plugin por completo si es `false`.    |
| `formats`        | `CalendarExportFormat[]`                                         | `['print', 'png', 'xlsx', 'ics']` | Formatos mostrados en el selector del diálogo.       |
| `filename`       | `string \| ((context: CalendarExportFilenameContext) => string)` | —                                 | Nombre base o función generadora de nombres.         |
| `pixelRatio`     | `number`                                                         | `3`                               | Multiplicador de resolución PNG predeterminado.      |
| `defaultOptions` | `Partial<CalendarPrintOptions>`                                  | —                                 | Opciones predeterminadas de impresión y visibilidad. |
| `license`        | `PackageLicenseConfig`                                           | —                                 | Configuración de licencia individual.                |

## CalendarPrintOptions

| Propiedad       | Tipo                             | Predeterminado | Descripción                               |
| :-------------- | :------------------------------- | :------------- | :---------------------------------------- |
| `allDayEvents`  | `boolean`                        | `true`         | Incluir eventos de día completo.          |
| `timedEvents`   | `boolean`                        | `true`         | Incluir eventos con hora.                 |
| `miniCalendar`  | `boolean`                        | `true`         | Mostrar mini calendario en el encabezado. |
| `calendarKeys`  | `boolean`                        | `true`         | Mostrar leyenda de calendarios.           |
| `blackAndWhite` | `boolean`                        | `false`        | Modo blanco y negro sin colores.          |
| `textSize`      | `'small' \| 'medium' \| 'large'` | `medium`       | Ajustar escala tipográfica y densidad.    |

## API del Plugin

```ts
type PrintPluginApi = {
  open: (options?: PrintDialogOpenOptions) => void;
  close: () => void;
  print: (config?: CalendarPrintConfigInput) => void;
  export: (request: CalendarExportRequest) => Promise<CalendarExportResult>;
};
```
