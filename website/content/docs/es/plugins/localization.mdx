# Plugin de i18n

El plugin de i18n añade soporte para varios idiomas y configuraciones regionales. De forma predeterminada, el núcleo de DayFlow solo incluye la locale inglesa (`en-US`) para mantener el bundle lo más pequeño posible.

## Instalación

Instala el paquete del plugin de i18n:

<PackageTabs pkg='@dayflow/plugin-localization' />

## Uso

Para habilitar más idiomas, registra el plugin y pásale las locales que necesites. La propiedad `locale` acepta tanto una cadena con el código de idioma (por ejemplo, `'zh-CN'`) como un objeto `Locale` importado directamente (por ejemplo, `zh`).

    import { useCalendarApp, DayFlowCalendar } from '@dayflow/react';
    import {
      createLocalizationPlugin,

    function MyCalendar() {
      const calendar = useCalendarApp({

## Configuración

El plugin acepta una lista de objetos `Locale` que se registran en el registro global de locales.

```tsx
interface LocalizationConfig {
  locales: Locale[];
}
```

## Locales disponibles

Estas son las locales disponibles actualmente en el paquete `@dayflow/plugin-localization`:

| Export | Idioma  | Código de locale                        |
| :----- | :------ | :-------------------------------------- |
| `zh`   | Chino   | `zh-CN`                                 |
| `ja`   | Japonés | `ja-JP`                                 |
| `ko`   | Coreano | `ko-KR`                                 |
| `fr`   | Francés | `fr-FR`                                 |
| `de`   | Alemán  | `de-DE`                                 |
| `es`   | Español | `es-ES`                                 |
| `fa`   | Persa   | `fa-IR`                                 |
| `en`   | Inglés  | `en-US` (también incluida en el núcleo) |

Al asignar la propiedad `locale` puedes pasar:

- **Un objeto `Locale`**: el objeto de locale importado directamente (por ejemplo, `locale: zh`).
- **Una cadena con el código**: un código de idioma (por ejemplo, `locale: 'zh-CN'` o `'zh'`), que se compara automáticamente con las locales registradas.

## Locales propias

También puedes registrar tus propias locales sin usar el plugin, o pasárselas a este:

```tsx
const myCustomLocale = {
  code: 'pt-BR',
  messages: {
    today: 'Hoje',
    day: 'Dia',
    week: 'Semana',
    month: 'Mês',
    // ... all other translation keys
  },
};

const calendar = useCalendarApp({
  plugins: [
    createLocalizationPlugin({
      locales: [myCustomLocale],
    }),
  ],
  locale: myCustomLocale, // Pass the custom Locale object directly (or code string 'pt-BR')
});
```

### Etiquetas accesibles

Los `messages` de una locale también proporcionan los nombres que los lectores de pantalla anuncian para los botones de solo icono y los campos sin etiqueta, así que tradúcelos junto con el texto visible. Las claves que falten en una locale propia recurren al inglés.

| Clave                                       | Se usa en                                                              |
| :------------------------------------------ | :--------------------------------------------------------------------- |
| `previousDay` / `nextDay`                   | Flechas de navegación de la cabecera en la vista de día                |
| `previousWeek` / `nextWeek`                 | Flechas de navegación de la cabecera en la vista de semana             |
| `previousMonth` / `nextMonth`               | Flechas de la vista de mes, del minicalendario y del selector de rango |
| `previousYear` / `nextYear`                 | Flechas de la vista de año y del selector de rango                     |
| `previousPeriod` / `nextPeriod`             | Flechas de navegación de la cabecera en la vista de agenda             |
| `clearSearch` / `closeSearch`               | Botón para borrar la búsqueda y botón atrás de la búsqueda móvil       |
| `close`                                     | Botones de cierre de diálogos y paneles laterales                      |
| `startDate` / `endDate` / `hour` / `minute` | Campos y listas de hora del selector de rango                          |
