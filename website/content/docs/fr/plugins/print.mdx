# Plugin d'Impression (Print Plugin)

`@dayflow-pro/plugin-print` ajoute une boîte de dialogue d'impression intégrée et un flux d'exportation multi-format pour DayFlow. Il prend en charge l'aperçu interactif des pages, le contrôle du format et de l'orientation du papier, le zoom par pincement sur pavé tactile, la prévisualisation tabulaire des données en direct et l'exportation programmatique headless.

| Format  | Sortie                                                                                                  |
| :------ | :------------------------------------------------------------------------------------------------------ |
| `print` | Boîte de dialogue d'impression du navigateur adaptée au papier sélectionné ; impression ou PDF          |
| `png`   | Image haute résolution par page imprimée ; les pages multiples sont téléchargées sous forme de ZIP      |
| `xlsx`  | Classeur Excel natif : feuille **Events** (événements) et feuille **Summary** (synthèse par calendrier) |
| `ics`   | Fichier iCalendar standard pour Google Agenda, Apple Calendrier, Outlook et autres applications         |

Essayez la [démo en direct](https://pro.dayflow.studio/?utm_source=calendar.dayflow.studio&utm_medium=referral&utm_content=docs_print).

Le plugin enregistre des méthodes d'assistance directement sur l'instance du calendrier :

```tsx
// Ouvre la boîte de dialogue avec le format par défaut
await calendar.app.openPrintDialog();

// Ouvre la boîte de dialogue avec un format ou une vue préconfigurée
await calendar.app.openPrintDialog({ format: 'xlsx', view: 'month' });

// Déclenche l'impression native du navigateur
await calendar.app.print();

// Exportation programmatique sans ouvrir l'interface
const result = await calendar.app.exportCalendar({
  format: 'png',
  view: 'week',
});
```

## Fonctionnalités principales

- **4 formats d'exportation** : Impression/PDF, PNG (page unique ou archive ZIP), Excel (.xlsx) et iCalendar (.ics).
- **9 formats de papier** : `A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`.
- **Boîte de dialogue d'aperçu interactif** : Échelle précise, zoom par pincement sur pavé tactile, panoramique et adaptation automatique.
- **Prévisualisation tabulaire des données** : Présentation interactive des données avant téléchargement lors de la sélection de `xlsx` ou `ics`.
- **Exportation headless** : Appel direct via `calendar.app.exportCalendar()` ou `printPlugin.api.export()`.
- **Filtrage par calendrier et catégorie** : Filtrage par calendrier, événements sur toute la journée et avec horaire.
- **Raccourci global** : Appuyez sur `Cmd + P` ou `Ctrl + P` pour déclencher la boîte de dialogue.

## Exportation par code (Headless)

```ts
const result = await calendar.app.exportCalendar({
  format: 'xlsx',
  view: 'month',
  startDate: new Date(2026, 8, 1),
  endDate: new Date(2026, 11, 1),
  calendarIds: ['work', 'personal'],
  download: true, // définir à false pour recevoir result.blob sans téléchargement automatique
  pixelRatio: 3, // multiplicateur de résolution PNG (1 = 96 DPI)
  onProgress: ({ completed, total }) => {
    console.log(`Page rendue : ${completed} sur ${total}`);
  },
});

console.log(result.filename); // 'calendar-2026-09_2026-12.xlsx'
console.log(result.eventCount); // nombre d'événements exportés
console.log(result.pageCount); // nombre de pages générées (0 pour xlsx et ics)
console.log(result.blob); // instance de Blob lorsque download: false
```

### Options de CalendarExportRequest

| Option        | Type                                                       | Valeur par défaut | Description                                                                          |
| :------------ | :--------------------------------------------------------- | :---------------- | :----------------------------------------------------------------------------------- |
| `format`      | `'print' \| 'png' \| 'xlsx' \| 'ics'`                      | Requis            | Format cible de l'exportation.                                                       |
| `view`        | `PrintView`                                                | Vue actuelle      | Mise en page (`day`, `week`, `month`, `year-fixed-week`, `year-canvas`).             |
| `paper`       | `PaperSize`                                                | Sélection act.    | Format de papier (`A3`, `A4`, `A5`, `B3`, `B4`, `B5`, `Letter`, `Legal`, `Tabloid`). |
| `orientation` | `'portrait' \| 'landscape'`                                | Défaut de la vue  | Orientation de la page.                                                              |
| `startDate`   | `Date`                                                     | Date actuelle     | Date de début de la plage d'exportation.                                             |
| `endDate`     | `Date`                                                     | Calculé auto.     | Date de fin de la plage d'exportation.                                               |
| `calendarIds` | `string[]`                                                 | Tous              | Identifiants des calendriers inclus.                                                 |
| `options`     | `Partial<CalendarPrintOptions>`                            | Valeurs plugin    | Options de typographie, légende et filtres d'événements.                             |
| `filename`    | `string`                                                   | Auto-généré       | Nom de fichier personnalisé sans extension.                                          |
| `download`    | `boolean`                                                  | `true`            | Si `false`, renvoie `result.blob` sans déclencher de téléchargement.                 |
| `pixelRatio`  | `number`                                                   | `3`               | Multiplicateur de résolution PNG (1 = 96 DPI).                                       |
| `onProgress`  | `(progress: { completed: number; total: number }) => void` | —                 | Callback de progression après chaque page PNG générée.                               |
| `signal`      | `AbortSignal`                                              | —                 | Signal pour annuler les exportations multi-pages en cours.                           |

## Configuration du plugin (PrintPluginConfig)

```ts
const printPlugin = createPrintPlugin({
  formats: ['print', 'png', 'xlsx', 'ics'],
  filename: ({ format, view, rangeStart, rangeEnd }) => `planning-${view}`,
  pixelRatio: 3,
  defaultOptions: {
    miniCalendar: true,
    calendarKeys: true,
    textSize: 'medium',
  },
});
```

| Propriété        | Type                                                             | Valeur par défaut                 | Description                                              |
| :--------------- | :--------------------------------------------------------------- | :-------------------------------- | :------------------------------------------------------- |
| `enabled`        | `boolean`                                                        | `true`                            | Désactive totalement le plugin lorsque défini à `false`. |
| `formats`        | `CalendarExportFormat[]`                                         | `['print', 'png', 'xlsx', 'ics']` | Formats proposés dans le sélecteur du dialogue.          |
| `filename`       | `string \| ((context: CalendarExportFilenameContext) => string)` | —                                 | Nom de fichier de base ou fonction de génération.        |
| `pixelRatio`     | `number`                                                         | `3`                               | Multiplicateur de résolution par défaut pour le PNG.     |
| `defaultOptions` | `Partial<CalendarPrintOptions>`                                  | —                                 | Options de visibilité et d'impression préconfigurées.    |
| `license`        | `PackageLicenseConfig`                                           | —                                 | Configuration de licence individuelle.                   |

## CalendarPrintOptions

| Propriété       | Type                             | Valeur par défaut | Description                                      |
| :-------------- | :------------------------------- | :---------------- | :----------------------------------------------- |
| `allDayEvents`  | `boolean`                        | `true`            | Inclure les événements sur toute la journée.     |
| `timedEvents`   | `boolean`                        | `true`            | Inclure les événements avec heure.               |
| `miniCalendar`  | `boolean`                        | `true`            | Afficher le mini calendrier dans l'en-tête.      |
| `calendarKeys`  | `boolean`                        | `true`            | Afficher la légende des calendriers.             |
| `blackAndWhite` | `boolean`                        | `false`           | Mode noir et blanc sans couleurs.                |
| `textSize`      | `'small' \| 'medium' \| 'large'` | `medium`          | Densité de la typographie et de la mise en page. |
